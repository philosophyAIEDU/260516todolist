# 개인 생산성 대시보드

## 실행
npm install
npm run dev

## Netlify 배포 방법

1. GitHub에 푸시
2. Netlify에서 "New site from Git" 선택
3. Build command: `npm run build`
4. Publish directory: `dist`
5. 배포 후 앱에서 직접 Gemini API 키 입력
   (Netlify 환경변수 설정 불필요 — 키는 브라우저에만 저장됨)

## Gemini API 키 발급
- https://aistudio.google.com/app/apikey 에서 발급
- 무료 티어 사용 가능
